Privacy and network

Are my files really never uploaded? Why should I believe it?

All processing is on-device. Only three enumerable network requests exist at runtime: one-time activation, the update check you choose to start, and OCR language packs you choose to install. File contents and filenames never go online. The site provides packet-capture self-check steps for Windows and macOS so you can verify it — we avoid the inaccurate "zero network requests" claim.

What does activation send? Are my files involved?

One-time activation sends only a SHA-256 hash of the device fingerprint to the activation service — irreversible, with no file contents, filenames or document data — to verify the device allowance for a license. The service returns a signed offline activation token. No other device information is uploaded, and telemetry and logging are off by default. The update check you start and the OCR language packs you install only download data; they never upload local files.

Does it work offline?

Yes. Apart from first-time activation, a manually started update check, and installing OCR language packs, core editing is fully offline. Merging, compressing, annotating, in-place editing and document comparison all work with no network.

Editing, conversion and OCR

Can it reflow like Word, or convert to Word/Excel with high fidelity?

No — and we say so. F19 is in-place replacement with no reflow; longer text may cover what's to the right, and you're warned before committing. High-fidelity Word/Excel conversion and WYSIWYG editing are out of scope. F14 exports the text layer (TXT/HTML/DOCX/XLSX) without preserving layout, tables or images.

Does it support signatures? Checkboxes or stamps?

You can create AcroForm text-field signatures, watermarks and password encryption. Checkboxes, radio buttons, dropdowns, calculation scripts and handwritten stamps are not supported; the tool refuses clearly rather than silently corrupting the file.

Can I edit or compare scanned documents?

Scans have no text layer — run local OCR first (optional language packs, including Simplified Chinese and English). Only then can you box-select edit or compare text layers. With no text layer the tool says so explicitly and never reports "no differences" silently.

What does document comparison check?

Text layers only, with per-page additions, deletions and changes, exportable to a TXT report. It doesn't recognize image or layout changes; when page counts differ, extra pages are listed as whole-page adds/deletes. Results for contracts, financial and legal documents need human review.

Does compression lose the text layer?

The acceptance target is 20MB down to ≤5MB with the text layer kept searchable and copyable. This isn't an absolute "lossless" promise — if a particular source can't retain the text layer, the tool says so rather than silently producing an unsearchable file.

Systems, licensing and purchase

Which systems? How many machines per license?

Windows 10/11 and macOS 11+ (Apple Silicon and Intel). One license covers up to 3 devices, no account, offline key validation. Mobile/iOS is not supported.

Do I need a subscription or a card? What about refunds?

No. The 7-day full trial needs no account and no credit card. $39 / ¥199 once, 12 months of 1.x updates, 7-day no-questions refund. A buyout is not a subscription — there is no auto-renew. The domestic payment channel is not open yet; CNY prices are indicative.

What happens when the trial ends? Are files deleted?

No file is deleted or modified — only export is paused. Users who haven't bought see an in-app payment window: click to pay on Gumroad, then enter the activation key. Buyers who already activated switch to the lifetime buyout automatically and see no window. There is no automatic charge at expiry.

What's the difference between "Buy" and "Download"?

Both install the same app and both start with a 7-day trial. Buyers pay first and get an activation key, so the trial switches to lifetime automatically at expiry; download users get the in-app payment window at expiry.

Where do I buy?

We plan to sell on Gumroad. Payments are being set up and are not open yet; when they open, this page will link to checkout. Until then you can subscribe for a launch reminder or try it free for 7 days.

Is the installer safe?

We keep a whitelist of open-source components (PDFium, qpdf, Tesseract, lopdf) and avoid AGPL-licensed code. Updates are signature-verified, with the previous version kept if verification fails. The installer is still in signing/release preparation — we won't fake a clickable download link before it ships.
