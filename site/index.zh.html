能做什么

为就地修订而生，附带十五个工具。

下面这十五个工具是配套，不是主打：就地修订（改字、批注、脱敏、水印、页面管理）才是主用途；合并、拆分、OCR 与文字层导出是辅助，我们刻意不卖保版式的 Word/Excel 转换。文件处理没有服务器往返、没有页数限制、没有上传步骤。功能面直接对标免费桌面编辑器：不必为了把文件留在自己电脑上而牺牲能力。唯一例外：你主动安装可选 OCR 语言包时会下载一份公开字典（请求只含语言代码，不含任何文件），详见 隐私说明。

01 / 合并合并

合并上百个 PDF，可排序、可删除，可选保留书签。加密文件仅在已知密码时读取。

02 / 拆分拆分

按页码范围、每 N 页或书签层级拆分，文件名模板可配置。

03 / 压缩压缩到指定大小

输入目标大小（如「小于 5MB」），而不是猜画质。文字层与书签保留。

04 / 图片互转PDF ↔ PNG/JPG

按 72/150/300 DPI 导出，或将图片合成为 PDF。文档可另导出文字层（TXT/HTML/DOCX/XLSX），仅文字、不还原版式。

05 / OCR本地 OCR

用本机 Tesseract（随包英文 + 简体中文，另有 40 种语言可按需安装）把扫描件变成可搜索 PDF 或 TXT。识别全程本机，不上传云端。

06 / 签名签名与表单

放置图片签名，填写表单字段，并「扁平化」使字段不可再编辑。

07 / 批量批量

对文件夹内所有 PDF 应用九种操作之一，输出带错误码的 report.csv。失败文件不中断队列，也不损坏原件。

08 / 改文字就地改字

看 PDF 时发现几个字要改？不用转 Word，不用订 Acrobat，直接改原 PDF。支持英文、中文与 ± ° µ × ÷ 等常见符号；≈ ≤ ≥ ∑ ∫ √ π 这类数学符号，需要原 PDF 已内嵌含这些字形的字体。不重排；原字体缺字形时明确报错，绝不写乱码。改完可接着框选别处继续改，多处改动累积在同一份 _edited 文件里，原件始终不变。

09 / 批注高亮与便签

按文字查找后添加高亮、下划线、删除线、波浪线或便签，生成标准 PDF 注解，Adobe Reader 等阅读器都能读取。

10 / 页面页面管理

旋转、删除、抽取、插入空白页、裁剪（改 /CropBox，可还原），不重排版面。

11 / 水印水印与保护

加水印、页眉页脚、页码与文档属性，设置 AES-256 打开密码与权限位。水印文字支持中文（系统 CJK 字体嵌入，写进真实文本层）；页眉页脚仍限拉丁字符。

12 / 导出可编辑文字稿

本机生成 TXT / HTML / DOCX / XLSX。诚实边界：只导出文字层，不还原表格、图片与版式。

13 / 文档对象表单 / 脱敏 / 书签

创建可填写的 AcroForm 文本域；真脱敏（先删文字对象再盖黑框，复制粘贴也取不到原文）；顶层书签查看、新建、重命名与删除。

14 / 文本转 PDFTXT / CSV / HTML 转 PDF

把纯文本排成 A4 PDF，中文用系统 CJK 字体嵌入。诚实边界：纯文本排版，不还原 Office 版式、表格与图片。

15 / 打印与扩展打印 / 邮件 / 语言包

交给系统默认阅读器打印、用邮件客户端预填主题正文；按需安装 42 种 OCR 语言包（唯一运行时联网点，请求只含语言代码）。打印无应用内预览，邮件附件需手动添加。

不支持清单

明确写清楚「不支持」。

我们宁可先把话说清楚，也不夸大。如果你需要以下能力，PayOnce PDF 并不合适。

  • 高保真 Word / Excel / PPT 转换：只把文字层导出为 DOCX/XLSX/TXT/HTML，不还原表格、图片与版式。需要逐像素还原请不要买我们。
  • 类 Word 的可视化编辑器：可以就地替换既有文字，但没有光标编辑、段落回流、拖拽内嵌对象。
  • 加密 / DRM 破解：仅移除你已知的密码，或设置你提供的密码，不破解、不绕过保护。
  • 移动端：仅桌面端，Windows 10/11 与 macOS 11+。
  • 企业 SSO / 审计：无账号、无目录集成、无集中日志。
  • 「AI 聊天读 PDF」：不做。部分免费编辑器会把文档内容发到云端大模型；我们拒绝增加任何云端文件处理路径，因为「文件内容绝不出本机」正是免费工具给不了的承诺。
  • 类 Word 之外的对象编辑、图章绘图、复选框/单选/下拉表单域：不做。 v1 的表单创建只提供文本域，书签只做顶层，详见 FAQ。
  • 应用内打印预览、邮件自动附加附件：不做；打印交给系统阅读器，邮件附件需在客户端手动添加。
诚实说明：功能面对标免费桌面编辑器已补齐到 15 个工具，但仍有明确落后项（可视化编辑器、图片/形状/链接编辑、图章绘图、复选框等表单域、网页版、macOS 签名包）。我们把能做的做可靠、做不到的写清楚，不宣称「功能全面超越」。OCR 与压缩的已知限制见 常见问题。
