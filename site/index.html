What it does

Built for in-place revisions. Fifteen tools ship with it.

The fifteen tools below are the supporting cast, not the headline: in-place revision (edit text, annotate, redact, watermark, manage pages) is the main use case. Merge, split, OCR and text-layer export are helpers; we deliberately do not sell pixel-faithful Word/Excel conversion. Every document operation runs locally. No server round-trip, no page limits, no upload step. We benchmark our feature list against free desktop PDF editors, so you do not have to give up capabilities to keep your files on your machine. One exception: if you choose to install an optional OCR language pack, a public dictionary is downloaded — the request contains only a language code, never any file. See the privacy notes.

01 / MergeMerge

Combine hundreds of PDFs, reorder and remove files, keep bookmarks (optional). Encrypted files only open with a password you already know.

02 / SplitSplit

Split by page range, every N pages, or by bookmark level, with a configurable filename template (default {name}_{index}.pdf).

03 / CompressCompress

Enter a target size (for example “under 5 MB”) instead of guessing quality. The text layer and bookmarks are preserved.

04 / ImagesPDF ↔ PNG/JPG

Export pages at 72/150/300 DPI, or turn images into a PDF. For documents, export the text layer to TXT, HTML, DOCX or XLSX — text only, no layout reconstruction.

05 / OCRLocal OCR

Turn scans into a searchable PDF or TXT with on-device Tesseract (English + Simplified Chinese bundled; 40 more languages installable on demand). Choose a page range. Recognition always stays on your machine.

06 / SignSign & forms

Place an image signature, fill form fields and flatten them so they can no longer be edited.

07 / BatchBatch

Point at a folder and apply any of nine operations to every file. Get a report.csv with error codes; a failed file never stops the queue or damages the original.

08 / Edit textFix text in place

Found a typo while reading? Replace it directly in the original PDF — no Word round-trip, no Acrobat subscription. English, Chinese and common symbols (± ° µ × ÷) are supported; math symbols such as ≈ ≤ ≥ ∑ ∫ √ π work when the PDF already embeds a font that contains them. No reflow; if a font lacks a glyph we return a clear error instead of writing garbage. Keep dragging to fix more spots — every change accumulates in the same _edited file, and your original is never touched.

09 / AnnotateHighlight & notes

Search for text and apply standard PDF highlight, underline, strikeout, squiggly or sticky-note annotations readable by Adobe Reader and other editors.

10 / PagesPage management

Rotate, delete, extract, insert blank pages or crop (via /CropBox, reversible) without rebuilding the layout.

11 / WatermarkWatermark & protect

Add a watermark, header, footer and page numbers, edit document properties, and set an AES-256 open password plus permission bits. Watermarks support Chinese (embedded system CJK font, real text layer); headers and footers remain Latin-only.

12 / ExportEditable text output

Generate TXT / HTML / DOCX / XLSX from the PDF text layer on your machine. Honest limit: text only, no tables or images restored.

13 / ObjectsForms / redaction / bookmarks

Create fillable AcroForm text fields; true redaction (the text object is deleted before the black box is drawn, so copy-and-paste cannot recover it); view, add, rename and delete top-level bookmarks.

14 / Text to PDFTXT / CSV / HTML to PDF

Lay out plain text into A4 pages with an embedded system CJK font for Chinese. Honest limit: plain-text layout only — no Office formatting, tables or images restored.

15 / Print & extrasPrint / mail / languages

Hand the file to the system printer or open a pre-filled mail draft; install any of 42 optional OCR language packs (the only runtime network request, containing just a language code). No in-app print preview; mail attachments must be added manually.

What it does not do

A clear “not supported” list.

We would rather say no up front than overpromise. If you need any of the following, PayOnce PDF is not the right tool.

  • High-fidelity Word / Excel / PPT conversion — we export the text layer only to DOCX/XLSX/TXT/HTML. Tables, images and layout are not restored; do not buy us for pixel-faithful conversion.
  • A Word-like visual editor — we replace existing text in place, but there is no cursor editing, paragraph reflow or drag-and-drop of embedded objects.
  • Encryption / DRM cracking — we only remove a password you already know, or set one you supply. We do not break or bypass protection.
  • Mobile apps — desktop only: Windows 10/11 and macOS 11+.
  • Enterprise SSO / audit — no accounts, no directory integration, no central logging.
  • “AI chat with your PDF” — not part of this product. Some free editors send document content to a cloud LLM for this feature; we refuse to add any cloud document-processing path, because “file contents never leave your computer” is the one promise a free tool cannot make.
  • Editing images, shapes, links and text boxes; stamps and drawing; checkbox / radio / dropdown form fields — not included. v1 form creation offers text fields only, and bookmarks are top-level only. See FAQ.
  • In-app print preview and automatic mail attachments — not included; printing is handed to the system viewer and mail attachments must be added manually.
Honest scope: the feature list now matches a free desktop editor across fifteen tools, but clear gaps remain (a visual editor, image/shape/link editing, stamps and drawing, checkbox-style form fields, a web version, a signed macOS build). We make what we do reliable and state what we cannot do; we do not claim to be ahead on every feature. See the FAQ for known OCR and compression limits.
