## 0. 结论先行

**拍板：主要用途 = 「桌面离线、一次买断的 PDF 就地修订」。**

不是用户给的三个选项里选一个，而是把它们分层：

| 层 | 用途 | 定位 | 是否收费 |
|---|---|---|---|
| **形态层（必需，不收费）** | 单纯阅读 + 批注 | 用户打开文档、看到那一页的界面；F17 内置阅读视图已落地 | 免费工具全覆盖，**收不到钱** |
| **核心层（唯一收费点）** | **就地修订**：改几个字、批注、真脱敏、水印页码、页面管理 | 看 PDF 时发现不对，直接在原文件上改掉，不转格式、不重排版、不订阅 | **$39 / ¥199** |
| **辅助层（保留，不主打）** | 文字层导出 TXT/HTML/DOCX/XLSX、图片互转、本地 OCR | 有比没有好，但不构成购买理由，不承诺保版式 | 含在单档内 |
| **排除层（明确不做）** | 高保真 Office 保版式转换、WYSIWYG 深度排版、云端 AI、移动端、云同步 | 撞商业 SDK / ~200 MB 体积 / 支持成本 / PRD §19 | — |

**一句话定位**：*看 PDF 时顺手把几个字改掉——一次买断，文件不出门。*

这条正好是用户本人最初提出的场景（「在 Acrobat Reader 中编辑要收费……我更喜欢直接在原 PDF 上修改」），也是 `docs/updf-gap-analysis.md` 指出的形态级缺口补完后的自然落点。

## 2. 三个候选用途逐一评估

### A. 单纯阅读 + 批注

- **规模最大**：Smallpdf 引 Statista 称 63% 的 PDF 查看发生在移动端、72% 的编辑仍在桌面；移动端功能细分里 View & Annotate 占 22.1%–28.7%（口径打架，仅作量级参考）。
- **付费意愿≈0**：Acrobat Reader、Chrome / Edge / Safari 内置查看器、macOS Preview 全部免费且已装好，都能高亮、加注释、填表、签名。**免费替代最完整的一条赛道**。
- **结论**：作为**形态必需**（没有阅读视图，就地改字就看不见那一页，见 `docs/updf-gap-analysis.md`），但作为主用途必死——它无法承载 $39 的价格。F17 已落地，定位上写成「工作台」，不写成卖点。

### B. 格式转换

- **规模大**：Adobe 文档云调查（厂商自述）称 98% 金融从业者会 edit/sign/combine/convert，1/3 每月 11 次以上；Smallpdf / iLovePDF 靠转换获客；Edit & Convert 在移动端细分占 25.3%–34.2%。
- **但我方经济性最差**，四条硬伤：
  1. **免费额度充足**：iLovePDF 免费层、Smallpdf 免费层、Sejda 3 任务/小时、PDF24 全免费、LibreOffice 免费、Stirling PDF 自托管。定价决策 §2.1 已确认「买断价对免费本地派是劣势，不是优势」。
  2. **做不出保版式**：14 格式保版式互转需商业 SDK 或 ~200 MB LibreOffice，撞 PRD §8 体积上限与单档 $39；现状 F14 只是**文字层导出**，不能对外当转换卖点。
  3. **边际成本与成本结构冲突**：云端转换有持续算力支出，与 PRD §1.2「本地处理 ≈ 0」这一整个商业模型的地基冲突。
  4. **支持成本最高**：旧语料「格式转换收费或失败 8%」+「编辑后文件损坏 7%」是差评高发区。转换质量投诉正是最容易击穿 PRD §18「≤0.1 封/单」的类型；定价决策 §3 已算出 0.5 封/单会吃掉 18.8% 净收入。
- **结论**：保留轻量文字层导出作为辅助，**不主打、不承诺保真度、不进主标题**。

### C. 深度修改文字排版（WYSIWYG）

- **客单价最高**：这是 Acrobat Pro / UPDF 的核心收费点，也是唯一能支撑高价的用途。
- **但做不了**：需商业排版 SDK 或自研段落回流/对象拖拽引擎，多年迭代；PRD §22.4 明确「不做 WYSIWYG 编辑器」，理由正是与 ≤0.1 封/单支持预算、买断定价、六周排期冲突；用户已授权暂缓高保真 Word/Excel。
- **结论**：硬约束，明确不做，官网明示。不因「市场规模大」放宽。

### D. 第四选项：就地修订（本次拍板）

用户给的是三选一，但真正可行的是三者之间被忽略的一层：**不重排版、不转格式，只在原 PDF 上把错字/敏感信息/页面标记改掉**。

| 维度 | 证据 |
|---|---|
| 需求 | 编辑与表单 11%（第二大痛点，3.6）+ 补验 7 条 3.4；40% 的付费订阅痛点里，大量正是「想改几个字却要订 Acrobat」；用户本人原始场景 |
| 供给 | **已全部落地且全部本地**：F10 就地改字（真实 PDF 字节级验证通过）、F11 批注、F15 真脱敏（先删文字对象再盖黑框）、F12 水印/页码/加密、F13 页面管理、F17 阅读视图、写后读回校验 |
| 竞争 | Acrobat Reader 把「改已有文字」锁在付费墙后（2026-11 复核仍成立）；PDFgear 免费能做但闭源、商业模式不透明、AI 走 Azure OpenAI 会传文档内容；Smallpdf/iLovePDF 要上传 |
| 经济 | $39 客单、边际成本≈0、**支持面窄**（不重排版就不会产生「版式跑掉了」这类工单），是四个选项里唯一同时满足「能收费 + 做得到 + 可不上传」的 |

### 2.5 加权评分（结构化判断，非测量结果）

权重是假设，分数是 1–5 的判断，**不是数据**，仅用于把讨论显性化：

| 维度 | 权重 | A 阅读批注 | B 格式转换 | C 深度排版 | D 就地修订 |
|---|---|---|---|---|---|
| 需求规模 | 0.20 | 5 | 4 | 2 | 3 |
| 付费意愿 | 0.25 | 1 | 2 | 5 | 4 |
| 免费替代压力（分高=压力小） | 0.20 | 1 | 1 | 3 | 3 |
| 实现成本（分高=我方省） | 0.15 | 5 | 2 | 1 | 5 |
| 边际成本与支持（分高=轻） | 0.20 | 4 | 2 | 1 | 4 |
| **加权总分** | 1.00 | **3.00** | **2.20** | **2.60** | **3.75** |

D 胜出的原因不是规模最大，而是**唯一没有致命短板**：A 收不到钱、B 毛利与支持最差、C 做不了。

## 3. 最终收益模型（现行价 $39 / ¥199）

沿用 `docs/pricing-decision.md` §3 的单位经济，未引入任何新假设：

```
直连净收入/单 = 0.871P − 0.80 = 0.871×39 − 0.80 = $33.17
Discover 净收入/单 = 0.70P = $27.30
固定成本中值 $475/年（Apple $99 + EV/Authenticode ~$300 + 域名 ~$15 + 更新端点 ~$60，不含人力）
```

| 指标 | 直连 | Discover |
|---|---|---|
| 盈亏平衡单数 | **15 单**（14.32） | **18 单**（17.40） |
| PRD §18 90 天目标 300 单净收入 | **$9,951** | $8,190 |
| 300 单摊到月均 | **$3,317/月** | $2,730/月 |

**支持成本敏感性**（每封 15 分钟、机会成本 $50/h）：

| 实际支持量 | 每单成本 | 占直连净收入 |
|---|---|---|
| 0.1 封/单（PRD 假设） | $1.25 | 3.8% |
| 0.3 封/单（未签名期很可能） | $3.75 | 11.3% |
| 0.5 封/单 | $6.25 | 18.8% |

→ **选 B（转换）会系统性把支持量推向 0.3–0.5 封/单**；选 D（就地修订，不重排版）是守住 0.1 封/单的前提。这是「最终收益」层面对主用途最硬的约束，比市场规模更决定性。

**分发漏斗（必须写明，否则收益是幻觉）**：

| 环节 | 转化率 | 达成 300 单需要 |
|---|---|---|
| 商品页访客 → 买家 | 3.2%（Gumroad 均值） | **9,375 商品页访客** |
| 文章读者 → 商品页 | ~3% | — |
| 文章读者 → 买家（端到端） | ~0.096% | **约 312,500 次内容阅读** |
| 流量来源 | 邮件 42% / 社交 23% / 直接 18% / 自然搜索 12% / 联盟 5% | Gumroad 不会主动送流量 |

→ **瓶颈是分发，不是功能宽度。** 这与 `docs/pricing-decision.md` §5、PRD §1.4 假设 H3 一致：再多选一个用途、再加几个功能，都不会改变 312,500 这个数；能改变它的是受众与渠道。所以「突出功能特色」的目的应该是**提高商品页转化率与搜索命中**，而不是堆功能数量。

> 诚实边界：3.2% 是**数字内容商品**的平台均值，不是桌面软件、不是本站实测；312,500 是量级估算不是预测；PRD §1.4 三个假设、预购 A/B、自然流量占比 **至今全部未验证**。

## 4. 赛道重定义与竞品相对优势

**关键动作：不要把自己放在「全能 PDF 编辑器」赛道。** 那条赛道上 UPDF 有 14 格式互转、100+ 贴纸、4 平台、云同步、AI，Acrobat 有三十年生态，逐项比功能宽度必输（见 `docs/updf-parity-decision.md` §0）。

**同赛道 = 「桌面离线、一次买断的轻量 PDF 修订工具」**，对标对象按用户任务而不是按厂商规模重排：

| 竞品 | 与本赛道的关系 | 它的强项 | **我方相对优势（可验证）** | 不能碰的说法 |
|---|---|---|---|---|
| **Adobe Acrobat Pro / Reader** | 最直接替代：Reader 免费看、改字要订 Pro | 全能、品牌、生态、跨端 | $39 一次 vs $239.88/年；无账号、不绑卡、无自动扣费（对应 40% 痛点）；**Reader 改已有文字至今锁付费墙** | 不比功能宽度、不比 AI、不说「比 Adobe 快」 |
| **PDFgear** | 最强免费替代 | 免费、功能更宽、跨平台、能就地改字 | 三类请求可枚举且可抓包核对、文件永不上传（对方 AI 走 Azure OpenAI 会传文档内容）、无广告/评分弹窗、写后读回校验不覆盖输入、批处理 `report.csv` 带 `error_code` 可审计、明码标价 vs 闭源且商业模式不透明 | **绝不能写「没有免费替代」「功能比它强」**（用户已两次纠正） |
| **Smallpdf / iLovePDF / Sejda / PDF24** | 转换赛道，不是同赛道 | 免安装、免费额度、转换保真 | 文件不上传、无每日次数限制、不注册、断网可用 | 不比转换质量与格式数量 |
| **UPDF / Foxit / PDF-XChange / PDFelement** | 买断同业 | 成熟、功能宽度、平台数 | 30.18 MiB vs UPDF 177 MB(+1.4–1.68 GB OCR 插件)；无 AI 加购（对方 $69/年）、无账号、$39 vs $84.99 / $209.99 | 不比平台数、不比移动端、不比批注种类 |
| **浏览器 / 系统自带查看器** | 形态对照 | $0 且已装好 | 不作为竞争对手，只解释「为什么我们仍要做阅读视图」 | 不在阅读批注上收费 |

**三条可防守的差异化，按数据排序**（沿用定位 v2 口径，未改）：
1. **不订阅**（40% / 3.8）——一次买断、授权不过期、12 个月 1.x 更新边界写死；
2. **不上传**（文件与文件名永不上传，三类请求可抓包验证，见 `site/verify.html`）；
3. **无广告 / 评分弹窗**（6% / 3.8）。

**新增第四条（本次由主用途推出）**：**不逼你转格式**——看 PDF 时发现错字，就在原文件上改掉，不用先转 Word 再转回来，也不用为了三个字订一年 Acrobat。这条把三条抽象承诺落到一个可演示的 10 秒动作上，是商品页转化最该突出的东西。
