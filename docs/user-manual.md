# PayOnce PDF 用户手册（v1，中文）

> 适用版本：v1.0（Windows 10/11 + macOS 11+）。本手册对应 `CONTRACT.md` 的命令与 `PRD.md` §7 的功能。
> 产品定位：**不订阅、不注册、不上传**的本地 PDF 工具箱。全部处理在本机完成，除「首次激活」外不需要联网。

## 1. 安装

### 1.1 系统要求

| 平台 | 要求 |
|---|---|
| Windows | Windows 10 1809+（x64），`.msi` 或 `.exe` 安装包 |
| macOS | macOS 11+，通用二进制（Apple Silicon + Intel），`.dmg` |

### 1.2 Windows 安装

1. 下载已签名的 `.msi` / `.exe`（安装包使用 EV 证书或 Azure Trusted Signing 签名）。
2. 双击运行，按向导完成安装。若 SmartScreen 出现警告，说明安装包未正确签名，请勿继续并联系支持。
3. 首次启动：没有登录、没有邮箱、没有账号。直接进入 **7 天全功能试用**。

### 1.3 macOS 安装

1. 下载 `.dmg`，打开后把 PayOnce PDF 拖入「应用程序」。
2. 发行版使用 Apple Developer ID 签名，并经过 `notarytool` 公证与 staple，Gatekeeper 应直接放行。**本应用不上 Mac App Store**（沙箱会限制 sidecar 与任意文件访问）。
3. 若出现「无法打开，因为无法验证开发者」：右键点击应用 → 「打开」，或前往「系统设置 → 隐私与安全性 → 仍要打开」。
4. 如果应用**未**被公证，请不要绕过 Gatekeeper，直接联系支持 —— 这可能不是官方构建。

### 1.4 组件自检

打开「关于 / 网络活动」可查看内置组件状态：`qpdf`、`tesseract`、`pdfium`、`tessdata` 是否就绪，以及平台与架构。若任一组件 `ready = false`，处理时可能返回 `E2001` / `E2002` / `E1006`，请重新安装对应平台的完整包。

## 2. 界面一览

| 区域 | 内容 |
|---|---|
| 左侧 | **十五个功能入口**：合并 / 拆分 / 压缩 / 转换 / OCR / 签名 / 批量 / **改文字 / 批注 / 页面 / 水印 / 导出 / 文档对象 / 文本转 PDF / 打印与扩展**；底部「关于 / 授权 / 网络活动」。项目多时侧栏可独立滚动，不挤压底部信息区 |
| 中间 | 拖拽区 + 文件列表（可排序、可删除，显示页数、大小、状态） |
| 右侧 | 参数面板，随功能切换（目标大小、DPI、语言、页码范围、文件名模板等） |
| 底部 | 进度条 + 取消 + 打开输出文件夹 + 状态文字 |

首屏固定一句话（英文原文）：**"Your files never leave this computer."**

- 所有写操作都输出到**你指定的路径**，绝不原地覆盖输入文件。
- 长任务可随时「取消」，取消后原文件不改动（错误码 `E2003`）。
- 临时文件写在系统临时目录下的 `payoncepdf-<jobId>/`，任务结束后清理。

## 3. 十五个功能逐步操作

### 3.1 合并（F1）

1. 左侧选「合并」，把多个 PDF 拖入中间列表；用列表排序、删除不需要的文件。
2. 右侧设置输出路径；按需勾选「保留书签」。
3. 若某个文件加密，在参数里输入**你已知的密码**（仅用于读取，不破解）。
4. 点「开始」，底部显示进度；完成后点「打开输出文件夹」。

| 参数 | 说明 | 默认 |
|---|---|---|
| 输出路径 | 合并后的单个 PDF | 必填 |
| 保留书签 | 是否保留输入文件书签 | 关 |
| 密码 | 已知密码，用于读取加密文件 | 空 |

验收：输出页数 = 各输入页数之和；100 个文件（合计 500MB）在 4 核机器上 ≤ 60 秒。
常见错误：`E1001`（损坏）、`E1002/E1003`（密码）、`E1004`（磁盘）、`E1007`（输出被占用）。

### 3.2 拆分（F2）

1. 选「拆分」，拖入单个 PDF。
2. 选择模式：**每 N 页一份** / **指定页码范围** / **按书签层级**。
3. 设置输出文件夹与文件名模板（默认 `{name}_{index}.pdf`）。
4. 点「开始」。

| 参数 | 说明 | 默认 |
|---|---|---|
| 模式 | everyN / ranges / bookmarks | 每 N 页 |
| N | 每份页数 | 10 |
| 页码范围 | 如 `1-5,8,11-` | 空 |
| 文件名模板 | 支持 `{name}`、`{index}` | `{name}_{index}.pdf` |

验收：500 页文件按每 10 页拆分，输出 50 个文件，页数与顺序正确。

### 3.3 压缩到指定大小（F3）

1. 选「压缩」，拖入 PDF。
2. 输入**目标大小**（例如「小于 5MB」），选择画质档位（自动 / 高 / 均衡 / 最小）。
3. 查看「预计大小 / 实际大小 / 画质档位」，确认后开始。

| 参数 | 说明 |
|---|---|
| 目标大小（字节） | 自动选择图像降采样与重编码参数 |
| 画质档位 | auto / high / balanced / small |

说明：压缩只重编码、降采样页面中的**图像**，**不改变文字层与书签**，压缩后文字仍可选中。
验收：20MB 扫描件压缩到 ≤5MB（目标大小 ±10%），文字仍可选中，肉眼无明显模糊（提供前后对比图）。

### 3.4 图片互转（F4，两个方向）

**PDF → 图片**

1. 选「转换」，选择方向「PDF → 图片」。
2. 设置格式（PNG / JPG）、DPI（72 / 150 / 300）、可选页码范围。
3. 设置输出文件夹，开始。

**图片 → PDF**

1. 选择方向「图片 → PDF」，拖入多张图片并调整顺序。
2. 设置页面大小（自动 / A4 / Letter）与边距。
3. 设置输出文件，开始。

| 参数 | 说明 | 默认 |
|---|---|---|
| 格式 / DPI | PNG 或 JPG；72/150/300 | JPG / 150 |
| 页码范围 | 只导出指定页 | 全部 |
| 页面大小 / 边距 | 图片转 PDF 时用 | 自动 / 0 |

验收：300DPI 导出 10 页 ≤ 30 秒；图片转 PDF 后页序正确。
**不支持 Word / Excel 转换**（见 §7 常见问题）。

### 3.5 本地 OCR（F5）

1. 选「OCR」，拖入扫描件 PDF。
2. 选择语言：英文（`eng`）、简体中文（`chi_sim`），可多选。
3. 选择输出格式：**可搜索 PDF**（叠加文字层）或 **TXT**。
4. 可选页码范围，设置输出文件，开始。

| 参数 | 说明 |
|---|---|
| 语言 | eng / chi_sim；语言包随包提供 |
| 输出格式 | 可搜索 PDF 或纯文本 TXT |
| 页码范围 | 只识别指定页 |

验收：10 页清晰扫描件 ≤ 60 秒；英文识别准确率 ≥ 95%、中文 ≥ 90%（标准测试集）。
**局限（诚实说明）**：清晰扫描件与简单版式效果良好；复杂表格、手写体、低分辨率/倾斜扫描、印章压字、特殊字体会明显下降。我们不承诺「100% 准确」，也不提供云端 OCR 兜底。语言包缺失会返回 `E1006`。

### 3.6 签名与表单（F6）

1. 选「签名」，拖入 PDF。
2. 放置手写或图片签名：拖放到页面，调整位置与大小（页码、x/y、宽高）。
3. 填写表单字段（键值对）。
4. 勾选「扁平化」（flatten）把字段与签名固化，之后不可再编辑。
5. 设置输出文件，开始。

| 参数 | 说明 |
|---|---|
| 签名图片路径 | 手写或图片签名 |
| 页码 / 坐标 / 宽高 | 定位签名 |
| 表单字段 | 字段名 → 值 |
| 扁平化 | 勾选后字段不可编辑 |

验收：签名后文件在 Adobe Reader 中显示正常；扁平化后字段不可再编辑。
注意：这里的「签名」是把签名图章放到页面上，**不是**数字证书 / 电子签章（不具备密码学签名效力）。

### 3.7 批量（F7）

1. 选「批量」，选择**输入文件夹**与**输出文件夹**（输出必须是新文件夹）。
2. 选择操作（共 9 种）：`compress` / `ocr` / `toImages` / `merge` / `edit` / `annotate` / `export` / `decorate` / `pages`。
3. 填写该操作对应的参数，开始。
4. 完成后在输出文件夹得到 `report.csv`。

要点：对文件夹内每个文件应用同一操作；单个文件失败会记录明确错误码，**不中断队列**；原文件绝不改写。
批量化是相对免费桌面编辑器的一项实际优势：可对整个目录做改字、批注、导出，并留下带 `error_code` 的逐文件台账。

### 3.8 就地替换文字（F10）

场景：在 Acrobat Reader 里看 PDF 时发现几处要修，不想转 Word、不想订 Acrobat，只想**直接改原 PDF**。

1. 选「改文字」，拖入**一个** PDF（当前只处理列表第一个文件）。
2. 填「查找」与「替换为」；可选「区分大小写」「全词匹配」「页码范围」。
3. 指定输出文件，开始。结果另存为新文件，**原文件不动**。

**边界（务必先看）**

- 只改**可选中文本**；扫描件请先走 F5 OCR。
- **不重排、不回流**：替换后的文字变长时可能压到右侧内容，请用阅读器目视确认。
- 中文可用，但沿用原 PDF 的字体；若原字体不含新字形，返回明确错误（E2004）而不是写出 `?` 或乱码。
- 一次查找可跨多个文本对象命中；被完全消费的对象会被移除，避免留下多余空格。

### 3.9 批注（F11）

1. 选「批注」，拖入一个 PDF。
2. 填要标注的文字、批注类型（高亮 / 下划线 / 删除线 / 波浪线 / 便签备注）、颜色（`#RRGGBB`）、作者与备注内容。
3. 指定输出文件，开始。

生成的是**标准 PDF 注解字典**（`/Highlight`、`/Underline`、`/StrikeOut`、`/Squiggly`、`/Text`），带 `/QuadPoints`、`/Contents`、`/T`，Adobe Reader、PDFgear、macOS 预览都能读取，且可以再编辑或删除，不是烫死在页面上的图片。

### 3.10 页面管理（F12）

选「页面」，选操作：`rotate`（旋转 90 的倍数）、`delete`（删除）、`extract`（抽取指定范围）、`insert`（插入空白页）、`crop`（裁剪）。
`crop` 只改 `/CropBox`，**不删除页面内容**，随时可改回；删除/抽取会重建页树，嵌套书签可能不随页号更新。

### 3.11 水印与保护（F13）

可一次叠加：水印文字（字号 / 角度 / 不透明度）、页眉、页脚、页码（页脚居中 / 页脚右侧 / 页眉右侧）、文档属性（标题 / 作者 / 主题 / 关键词），以及 AES-256 打开密码与打印/复制/修改权限位。

**边界**：

- **水印文字支持中文**：填写含非拉丁字符的水印时，自动用系统 CJK TrueType 字体（Windows 优先 `C:/Windows/Fonts/simhei.ttf`）嵌入并写进真实文本层，为**水平居中灰字**。此时「水印字号」生效，「水印角度 / 不透明度」不生效；找不到系统 CJK 字体会直接报错（E2004），绝不写方框或乱码。
- **页眉 / 页脚仍用 Helvetica/WinAnsi，只支持拉丁字符**；输入中文会直接报错（E2004）而不是写成乱码。
- 加密只设置你提供的密码，不破解已有密码；密码本机不保存，丢失无法找回。

### 3.12 导出文字层（F14）

选「导出」，选 `TXT` / `HTML` / `DOCX` / `XLSX`，可指定页码范围。DOCX/XLSX 由本机直接生成（ZIP + OOXML），不上传、不调用云端服务，也没有新增第三方依赖。

**诚实边界**：**只导出文字层，不还原版式、表格与图片**。这是可编辑的文字稿，不是商业 SDK 那种高保真转换。复杂排版请人工校对；扫描件会导出空页提示，请先 OCR。

### 3.13 文档对象（F15：表单 / 脱敏 / 书签）

选「文档对象」，拖入一个 PDF，在「模式」里三选一。三个模式共用右侧面板，各有独立字段。

**① 创建可填写表单**

每行一个文本域，格式：`页码|名称|x|y|宽|高|默认值|多行(0/1)|必填(0/1)`，例如：

```
1|buyer|72|700|200|24|ACME|0|1
1|memo|72|640|300|60||1|0
```

生成标准 **AcroForm Widget 注解**（`/FT /Tx`），写入 `/NeedAppearances true`，由 Adobe Reader / PDFgear 等阅读器自动生成外观。**不覆盖文档中已有的表单字段**；支持单行/多行/必填三种标记。

**边界**：只有文本域，没有复选框、单选按钮、下拉框、计算脚本或签名域；坐标以 PDF 点（pt）为单位，原点在页面左下角。

**② 密文脱敏（redaction）**

在「脱敏词」里按换行或逗号填入要抹掉的词，可设「区分大小写」与页码范围。

实现是**先真删除文字对象，再盖黑框**：脱敏后不仅看不见，连**复制粘贴也取不到原文**（这与「只盖一层黑框」的假脱敏有本质区别）。处理结果会在消息里报告删除词数、命中处数、黑框数与涉及页数。

**边界**：只处理**可选中文本**；扫描件请先走 F5 OCR。请用阅读器打开产物自行复核敏感信息是否确实消失。

**③ 书签管理**

先点「读取当前书签」查看现有书签（按层级缩进显示）。操作有四种：

| 动作 | 说明 |
|---|---|
| `set`（整体替换） | 用「书签定义」里的清单替换全部书签 |
| `add`（追加） | 在现有书签后追加 |
| `rename` | 把「目标标题」改名为「新标题」 |
| `delete` | 删除「目标标题」对应的书签 |

书签定义每行一条，格式 `[>...]页码 标题`：**行首 `>` 数量表示层级**（无 `>` 一级、`>` 二级、`>>` 三级……），如 `3 第三章 交付验收` 与 `> 4 3.1 验收标准`。标题可含空格、支持中文（用 UTF-16 写入）。层级不能跳跃——子级前面必须先有它的上一级，否则报错。

**边界**：层级由清单文本决定，**不支持界面拖放换父级**；`set/add/rename/delete` 都会保留已有层级，不会压平；页面增删后书签**不会自动跟随页号**，请人工核对。

### 3.14 文本转 PDF（F16）

选「文本转 PDF」，把 **TXT / CSV / HTML** 文本文件拖入列表（只处理第一个文件），选择源文件格式与输出路径，开始。

- 输出为 **A4 竖版**，11pt，每页 45 行自动分页；中文用**系统 CJK TrueType 字体嵌入**，不会变方框。
- HTML **只剥离标签**取文字，**不执行脚本、不渲染 CSS**；找不到系统 CJK 字体时明确报错而不是写乱码。

**诚实边界**：这是**纯文本排版**，不是 Office 高保真转换——不还原 Word/Excel 的版式、表格、列宽、图片、样式。需要保真请把原文件另存为 PDF。

### 3.15 打印与扩展（F16：系统打印 / 邮件 / OCR 语言包）

选「打印与扩展」，拖入一个 PDF（打印与邮件只处理第一个文件）。

**① 交给系统打印**：Windows 用 `Start-Process -Verb Print`、macOS 用 `lp` 把文件交给系统默认 PDF 阅读器，**打印对话框由阅读器显示**，PayOnce PDF 内没有打印预览。

**② 唤起邮件客户端**：生成 `mailto:?subject=...&body=...`，填好主题与正文并唤起系统邮件客户端。**mailto 无法可靠跨平台附加附件，PDF 附件需在客户端里手动添加**。

两种方式都**不上传文件**，命令返回时 `outputs` 为空数组，只有一段说明文字。

**③ OCR 可选语言包**

面板列出 **42 种** `tessdata_fast` 语言及已安装状态（随包自带 `eng` 英语 + `chi_sim` 简体中文）。需要其它语言时填入语言代码（如 `jpn` / `fra` / `deu`），点「安装语言包」。

> ⚠️ **这是 PayOnce PDF 全产品唯一的运行时联网点**：只在你主动点击安装时发生，下载 `https://raw.githubusercontent.com/tesseract-ocr/tessdata_fast/main/<语言代码>.traineddata` 到应用数据目录。**请求只含语言代码**，不含任何文件、文件名、路径、机器指纹或用户数据；下载的是公开静态字典，识别全程仍在本机完成。语言代码走白名单校验，过小的响应会被丢弃且不改动已有语言包。不安装也完全不影响随包的中英文 OCR。

因此正确的隐私承诺是「**文件内容永不上传 + 三类请求可枚举**」，而不是「零网络请求」。三类请求见 §6。

## 4. 批量 `report.csv` 字段说明

位置：输出目录下 `report.csv`（对应 `JobResult.reportPath`）。编码 UTF-8（不带 BOM）。

表头与 `src-tauri/src/commands/jobs.rs::batch_run` 的实现逐字一致，共 5 列：

| 列名 | 类型 | 说明 | 示例 |
|---|---|---|---|
| `filename` | string | 输入文件名，PRD §7 要求的"文件名" | `scan_003.pdf` |
| `elapsed_ms` | number | 单文件耗时（毫秒），PRD 要求的"耗时" | `1840` |
| `result` | string | `ok` / `failed` / `cancelled` / `blocked`，PRD 要求的"结果" | `failed` |
| `error_code` | string | 错误码，成功为空；失败为 `E1xxx` / `E2xxx`，PRD 要求的"错误码" | `E1002` |
| `output` | string | 输出文件路径，失败时为空 | `C:\out\scan_003.pdf` |

PRD §7 规定的四项必需字段全部包含；`output` 为便于定位产物的附加列。字段值经 CSV 转义（逗号、引号、换行）。

示例：

```csv
filename,elapsed_ms,result,error_code,output
a.pdf,920,ok,,out/a.pdf
b.pdf,310,failed,E1002,
c.pdf,1100,ok,,out/c.pdf
```

## 5. 快捷键

依据 `CONTRACT.md` §16：键盘可完成全部操作，有可见焦点、`Enter`/`Space` 触发、`Esc` 取消，并支持系统「高对比度」偏好（`prefers-contrast: more`）。

已实现的键盘操作（全部控件均为原生 `button` / `input` / `select`，带可见 focus 框）：

| 快捷键 | 功能 | 实现位置 |
|---|---|---|
| `Tab` / `Shift+Tab` | 在控件间移动焦点（可见 focus 框） | `src/styles.css` |
| `Enter` / `Space` | 触发当前按钮、拖拽区与列表项 | 原生控件 + `src/components/DropZone.tsx` |
| `Esc` | 取消当前任务 / 关闭对话框 | `src/App.tsx` → `cancel_job` |

v1 未提供 `Ctrl/⌘+O` 等自定义组合键；所有功能仍可通过 Tab + Enter 完整完成（PRD §8「键盘可完成全部操作」）。系统开启「高对比度」时界面自动切换（`prefers-contrast: more`），开启「减少动效」时禁用过渡动画。

## 6. 如何验证「不上传」

完整步骤见官网 **验证页**：`site/verify.html`。这里给出要点：

正确的承诺是「**任何文件处理功能都不联网；文件内容与文件名永不上传；所有运行时网络请求可枚举、可抓包验证**」，而不是「零网络请求」。

**三类运行时请求（完整清单）**：

| # | 请求 | 何时发生 | 发送内容 | 不含 | 可否关闭 |
|---|---|---|---|---|---|
| 1 | 首次激活 | 输入密钥激活一次 | 密钥 + 不可逆机器指纹哈希 | 文件内容、文件名、路径、元数据 | 只需一次，之后完全离线 |
| 2 | 可选更新检查 | 启动时，仅当开启 | 版本 / 平台 / 架构 | 任何文档相关数据 | 可在设置里关闭 |
| 3 | 安装 OCR 语言包 | **仅你主动点击安装** | URL 里只有一个语言代码 | 文件名、路径、机器指纹、任何用户数据 | 不点就不会发生；不装不影响中英文 OCR |

第 3 类下载的是公开静态字典（`<lang>.traineddata`），不调用云端处理或 AI 接口，识别仍在本机。这与某些免费编辑器把 **PDF 内容**发往云端大模型有本质区别。

**验证步骤**：

1. **准备 canary 文件**：在测试 PDF 里放一个唯一字符串（如 `PAYONCEPDF-CANARY-8F3A91`），抓包后全局搜索该串与 `%PDF-`，应为 0 命中。
2. **Windows**：Wireshark（含 Npcap）抓包看会话与包大小；Fiddler Classic 开启 HTTPS 解密，读取激活请求正文，确认只有密钥与哈希、没有 PDF 字节。
3. **macOS**：Little Snitch 网络监视器按进程过滤 `PayOnce PDF`，处理文档时不应出现新连接；Wireshark（需 ChmodBPF）做原始抓包复核。
4. **截获语言包请求核对**：主动安装一次语言包，确认目标主机是 `raw.githubusercontent.com`、路径只含语言代码、请求体为空、响应是 `.traineddata` 字典；同时确认 canary 串与 `%PDF-` 仍未出现在任何请求里。
5. **断网测试（最强）**：联网激活一次后，关闭 Wi-Fi/以太网或用防火墙禁止 PayOnce PDF 出站，逐个执行**十五个功能中除「安装语言包」外的全部操作**，确认都能完成并导出文件，且没有「请联网」提示。语言包安装是唯一需要联网的可选动作，断网时它会明确报错且不影响其它功能。
6. **异常反馈**：若发现文件内容外发，属严重问题，按 `site/verify.html` 的「异常反馈」提供 OS/版本/时间/操作/目标主机/抓包片段，联系 `hello@payoncepdf.com`。

## 7. 常见问题（摘要）

完整 19 条见官网 `site/faq.html`（新增第 17–19 条覆盖表单/脱敏/书签、中文水印与文本转 PDF、打印邮件与语言包联网口径）。高频几条：

- **真的离线吗？** 文件处理全部本机、文件内容永不上传。运行时只有三类可枚举请求：首次激活一次、可关闭的更新检查、**你主动点击**安装 OCR 语言包。不安装语言包的话，激活之后全部功能离线。我们不再宣称「零网络请求」。
- **为什么不做高保真 Word/Excel？** v1 明确不支持，版面还原不可靠，不夸大（PRD §19）。F14「导出」只导文字层，F16「文本转 PDF」只做纯文本排版。
- **加密 PDF？** 仅支持移除你已知的密码或设置你提供的密码，不破解、不绕过 DRM。
- **试用到期？** 只限制导出（`E2005`），绝不删除或改写文件；激活后恢复导出。
- **压缩会丢文字/书签吗？** 不会，文字层与书签保留。
- **中文水印能做吗？** 能。在「水印」的水印文字里直接填中文即可（水平居中灰字，用系统 CJK 字体嵌入）；但页眉/页脚仍只支持拉丁字符，填中文会明确报错。
- **脱敏后能复制出原文吗？** 不能。F15 脱敏是真删除文字对象再盖黑框，不是只盖一层黑框。

错误码的完整含义、触发条件与排查步骤见 `docs/error-codes.md`。

## 8. 卸载与日志清理

### 8.1 卸载

- **Windows**：设置 → 应用 → 已安装的应用 → PayOnce PDF → 卸载。
- **macOS**：把 PayOnce PDF 从「应用程序」拖到废纸篓。

### 8.2 本地日志

- 日志**默认关闭**；开启后**只记录操作类型与错误码**（如 `merge` / `E1002`），不记录文件名、路径、内容或元数据，也**从不上传**。
- 开关位置：左侧「关于」→「启用本地日志」（对应 `set_logging` 命令）。
- 日志文件名固定为 `payoncepdf.log`，位于 Tauri 的应用数据目录（identifier `app.payoncepdf.desktop`）：
  - Windows：`%APPDATA%\app.payoncepdf.desktop\payoncepdf.log`
  - macOS：`~/Library/Application Support/app.payoncepdf.desktop/payoncepdf.log`
- 关闭后可直接删除该文件；卸载不会留下云端数据（本就没有账号与服务器数据）。

### 8.3 临时文件与授权缓存

- 临时目录为系统临时目录下的 `payoncepdf-<jobId>/`，任务结束自动清理；异常退出后可在系统临时目录手动删除 `payoncepdf-*` 目录。
- 任何失败都不会损坏原文件；输出一律写到用户指定路径，绝不原地覆盖输入。
- 激活后在本机缓存一个签名令牌，之后离线可用。三个状态文件都在上面的应用数据目录：
  - `trial.json`：7 天试用起点 + SHA-256 摘要（绑定机器指纹，防随手改日期）
  - `activation.json`：Ed25519 验签通过的激活令牌（含密钥、指纹哈希、激活时间）
  - `update-settings.json`：更新检查开关与上次检查时间（F9）
- 重装系统、更换机器或删除该目录后需重新联网激活一次；删除这些文件不会触碰任何用户 PDF。
- 试用到期只限制导出（错误码 `E2005`），绝不删除或改写用户文件。
