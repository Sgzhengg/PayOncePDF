## 1. 两个入口

| 市场 | 页面 | 收款 | 定金 |
|---|---|---|---|
| 海外 | `landing.html` | Gumroad 预购商品 | $9 |
| 国内 | `landing.zh.html` | 爱发电 | ¥59 |

**定金必须可退**，且写明“90 天未交付自动退款”。这是合规底线，也是转化率的关键。

## 2. 上线前准备（半天）

1. Gumroad 建商品：`PDF Local — Early Access Deposit`，价格 $9，类型 digital，说明“refundable deposit”；
2. 爱发电建方案：`¥59 早鸟定金（可退）`；
3. Buttondown 建列表 `pdf-local`，把 landing 表单 action 换成你的地址；
4. 买一个短域名（可选，$10/年），没有就用 Gumroad 链接；
5. 埋点：每个渠道用不同 UTM 或不同折扣码（`REDDIT-PDF`、`PH`、`XHS`）。

## 4. 判定标准（提前写死）

| 指标 | 通过线 | 含义 |
|---|---|---|
| 落地页访问 | ≥ 500 | 渠道有效 |
| 邮箱 | ≥ 20（4%） | 兴趣真实 |
| 定金 | ≥ 5（1%） | 付费意愿成立 |
| 退款申请 | ≤ 2 | 承诺不过度 |

- 三项达标 → 开始写 MVP；
- 只有访问和邮箱达标 → 定金 0，说明“买断”不是卖点，改订阅或换品类；
- 访问都不够 → 渠道选错，不是产品问题。

## 5. 定金怎么履约

1. 记录每笔定金的邮箱、渠道、时间；
2. 交付日发邮件：补尾款链接 + 下载链接；
3. 未在 90 天内交付：**主动全额退款**，并发一封说明邮件；
4. 退款政策写进商品页与邮件，避免争议。

## 6. 需要提前想好的三个反对意见

| 反对 | 回应 |
|---|---|
| “免费网页工具就够了” | 免费工具要上传；你的客户是律师/会计/HR，文件不能出门 |
| “一次买断 $39，能长期维护吗” | 本地处理无云端成本、12 个月 1.x 更新边界写死、2.x 五折；7 天退款 + 90 天未交付自动退，风险为零 |
| “功能会不会很少” | 主用途是「就地修订」：看 PDF 时发现错字直接在原文件上改掉，不转 Word、不重排版。15 个工具入口含就地改文字、批注、脱敏、表单、书签、水印与加密，都是配套；不承诺类 Word 可视化编辑器与高保真 Office 转换 |
